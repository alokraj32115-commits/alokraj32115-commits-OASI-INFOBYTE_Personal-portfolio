👨‍💻 Personal Portfolio Website

📌 Project Overview

A modern and responsive Personal Portfolio Website created to showcase my profile, technical skills, projects, and contact information. The website works as a digital résumé and provides an easy way for visitors to learn more about me.

✨ Features

- Profile/Hero section with name, role, and professional photo/avatar
- About Me section
- Technical Skills section
- Projects section with project cards
- GitHub link placeholders
- Contact section with name and email
- LinkedIn and GitHub links
- Smooth scrolling navigation
- Consistent colour scheme and typography
- Fully responsive design for desktop, tablet, and mobile

🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries
- JavaScript (optional enhancements)

📂 Project Structure

Personal-Portfolio/
├── index.html
├── style.css
├── script.js
├── images/
│   └── profile.jpg
└── README.md

🚀 How to Run

1. Download or clone the project.
2. Open the folder in VS Code.
3. Open "index.html" in a browser.
4. For development, use the Live Server extension.

🎯 Purpose

This project is developed to practice frontend web development and create a professional online portfolio for showcasing skills and projects.
